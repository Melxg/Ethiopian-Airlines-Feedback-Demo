# HCI REQUIREMENTS

The prototype must visibly demonstrate these HCI principles:

## 1. Visibility of System Status

Always show:

* Recording state
* Upload/processing state
* Analysis state
* Submission success
* Current case status
* Active filters

## 2. Match Between System and Real World

Use familiar airline/customer-service terminology.

Avoid unnecessary technical AI terminology.

Use:

“Passenger Feedback”

“Customer Service”

“Review”

“Sentiment”

instead of technical machine-learning terminology.

## 3. User Control and Freedom

Provide:

Back

Cancel

Edit

Delete/Re-record

Submit

Return to dashboard

Users should be able to recover from mistakes.

## 4. Consistency

Buttons, colors, icons, terminology, cards, status badges, and navigation must remain consistent throughout the application.

## 5. Error Prevention

Validate forms before submission.

Prevent empty feedback.

Confirm destructive actions.

Allow review before final submission.

Handle microphone/camera permission errors.

## 6. Recognition Rather Than Recall

Use visible labels, icons, examples, breadcrumbs, clear navigation, and descriptive buttons.

Do not make users remember instructions from previous screens.

## 7. Flexibility and Efficiency

Allow passengers to choose text, audio, or video.

Allow agents to search and filter feedback quickly.

## 8. Aesthetic and Minimalist Design

Avoid unnecessary dashboards, charts, animations, or decorative elements.

Every interface element should support a user task.

## 9. Help Users Recognize and Recover From Errors

Errors should explain:

What happened
Why it happened
How to fix it

Example:

“Your microphone is unavailable. Check browser permissions or choose Text Feedback.”

## 10. Accessibility

Implement:

* Semantic HTML
* Proper labels
* Keyboard navigation
* Visible focus states
* Sufficient contrast
* ARIA labels where appropriate
* Icons accompanied by text
* Do not rely only on color
* Responsive layout
